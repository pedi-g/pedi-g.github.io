# Pedram Ghahramani — personal research website

Six separate pages: Home, About, Research, Publications, CV, Contact.

## Preview
Extract the ZIP, then open index.html in a browser. Keep all files together.

## GitHub Pages
Upload all HTML files plus styles.css, site.js and pedram.jpg to the root of your website repository. Do not upload the ZIP itself or put the files inside another folder. In repository Settings > Pages, choose Deploy from a branch, main, / (root), then Save. If your GitHub account is Orcinus93, the user-site repository name is Orcinus93.github.io. If that repository already exists, update it rather than creating a second user site.

If replacing the earlier single-file website, replace index.html and add every other file in this package. No build command, dependencies, or custom domain is required.

## Editing
Change the text inside the relevant HTML page. styles.css controls the shared design. site.js controls the mobile menu and the CV print button. pedram.jpg is the supplied portrait. All links are relative, so the site also works in a project repository.

The CV page has a Print / save PDF button. Use your browser print dialog to choose Save as PDF.

No analytics, contact-form service, cookies, or external fonts are included.
